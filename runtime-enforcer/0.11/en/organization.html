Documentation organization

The SUSE Security Runtime Enforcer documentation has these parts:

  • Introduction: what Runtime Enforcer is.

  • Quick start: install Runtime Enforcer and walk through the learn, monitor, and protect workflow.

  • Tutorials: how to verify the signatures of the release.

  • Explanations: the learn, monitor, and protect phases, and how the components are built.

  • How-tos: tasks for the operator and the contributor, such as the learning configuration, the kubectl plugin, troubleshooting, and the build and development environment.

  • Reference: the kernel and runtime requirements, the known limitations, the custom resource definitions, the kubectl plugin commands, and the resource consumption of the components.

  • For who?: the people who use Runtime Enforcer.

  • Use cases: what each persona does with it.

  • Organization: this page.

  • Glossary: the terms used in these pages.

  • Security disclosure: how to report a vulnerability.

Most of the content is in the Tutorials, Explanations, How-tos, and Reference sections. The sections can overlap. The Runtime Enforcer project follows the Diátaxis documentation framework where it can.
